# chatbot-mini
Created a lightweight mini chatbot using pure frontend technologies with all CSS and JavaScript embedded inside one HTML file. The chatbot provides predefined responses, requires no internet connection, and has no data persistence or voice functionality.

# Mini Chatbot (Single HTML File)

A simple rule-based mini chatbot built using **HTML, CSS, and JavaScript** in a **single HTML file**.  
The chatbot responds to predefined questions and works completely **offline** without any backend or API.

---

## 🚀 Features

- 💬 Predefined question–answer chatbot
- 📄 Single HTML file (CSS & JavaScript included internally)
- ⚡ Lightweight and fast
- 🌐 Works offline & online
- 🧠 No memory storage
- 🎤 No voice control
- 🔒 No backend / database / API required
- 📱 Responsive UI

---

## 🛠️ Technologies Used

- HTML5  
- CSS3 (internal styling)  
- JavaScript (inline scripting)

---

> All code (HTML, CSS, and JavaScript) is written inside **one file only**.

---

## 📌 How It Works

- The chatbot uses **conditional logic** or **keyword matching**
- Users type predefined questions
- The chatbot replies with fixed responses
- No data is stored or remembered

---

## ▶️ How to Run

1. Download or clone the repository  
2. Open `mini-chatbot.html` in any browser  
3. Start chatting 🎉  

_No internet connection required._
